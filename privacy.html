Privacy Policy

Last updated: October 3, 2026

Home Backup App is a private tool used by one person to copy backup files from their own home server to their own Google Drive.

What it accesses

The app uses Google Drive access limited to files and folders that the app itself creates. It cannot see any other files in the Drive.

What it collects

Nothing. The app has no server of its own, no analytics and no user accounts. Backup files go directly from the owner's server to the owner's Google Drive. No data is shared with, sold to or sent to anyone else.

Who can use it

Only the owner. It is not offered to the public.

Contact

Questions can be raised through the issue tracker of this site's GitHub repository.
